# fabric-dummy-data-generator
Fabric dummy Data Generator (FDDG) is an open-source repo aimed at providing fake data for Microsoft Fabric demos and training.

It follows the fictional company "Rockline Supplies", a construction materials wholesaler that sells products to construction companies and private individuals through several physical locations. 

The project sees that you can generate a Lakehouse in Microsoft Fabric containing dummy data for this company, with transactions and master data, in order to build your demos and training materials. 
The project contains Python notebooks to seed the Lakehouse with an initial load, and makes it possible to periodically load new data, faking actual transactions in the company so your dummy data will never be stale.
